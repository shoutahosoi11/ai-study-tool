# Screenshots Checklist

Use demo users and dummy data. Do not capture real email addresses, real names, tokens, secrets, cookies, signatures, webhook payloads, SSV query strings, prompts, or raw highlight text.

## Capture Rules

- Use a demo account such as `demo@example.invalid` or a masked staging account.
- Use dummy books and dummy highlights.
- Crop browser chrome if it shows private profiles or extensions.
- Confirm screenshots do not show devtools with secrets or request payloads.
- Prefer staging/local URLs or placeholders over real production URLs.
